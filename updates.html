v2.4 Deep Dive: Zero Ghosting & Temporal Consistency Engine

Complete breakdown of how motion smearing and buffer retention were eliminated

ENGINE BREAKTHROUGH
1. The Root Cause & Buffer Wiping

When writing pixel data via putImageData(), transparent pixels (A = 0) do not automatically wipe existing pixel values in the canvas memory. Uncleared previous frames caused moving hands and arms to leave persistent ghost trails. Calling strict offVideoCtx.clearRect(0, 0, vw, vh) on every single frame completely eliminates ghost artifacts.

2. Green Dominance & Despill Algorithm

Replaced fixed Euclidean color distance with dynamic Green Dominance Keying: diff = g - max(r, b). When light reflects green on hair or fingertips, the algorithm clamps data[i+1] = maxRB (despill), eliminating green halos and optical smearing.

3. Canvas State & Filter Isolation

Layer 1 backdrop filters (blur & shadows) are now wrapped in isolated save() / restore() blocks with explicit targetCtx.filter = 'none' resets before rendering Layer 2 (Presenter) and Layer 3 (Captions).

4. Frame-Accurate Video Decode Synchronization

The export engine coordinates with browser video decoders using a promise-based await seekVideo(targetTime) loop, ensuring zero dropped frames or temporal stutter before pixels are encoded into standard MP4 (H.264).

Pipeline Architecture Comparison
❌ Previous Flawed Pipeline

Uncleared 2D canvas buffer → Alpha mask applied over old frames → Moving hands leave smeared trails & multiple arm shadows.

✅ v2.4 Clean Isolation Pipeline

Mandatory clearRect per frame → Green dominance + despill → Isolated filter stack → Pristine motion tracking.

v2.3 Update: Animated Video Frame Sync & Universal MP4 Export

Fixed static video exports & added native macOS QuickTime / Windows MP4 support

LIVE
1. Frame-Accurate Video Animation

During export, the rendering engine now seeks the video frame-by-frame (await seekVideo(t)) so the presenter video in Layer 2 advances smoothly in exact synchronicity with the subtitles and background.

2. Native macOS & Windows MP4 (H.264)

Exported videos now default to Standard MP4 (H.264 / AVC) with fast-start headers. When downloaded, you can double-click and play them directly in macOS QuickTime Player, Spacebar Quick Look, Windows Media Player, and Canva without compatibility errors!

Contains your animated subtitle layer exported from SubWebM Alpha. When exported as Canva Transparent Overlay (.png) or QuickTime Alpha (.mov), all empty regions have an alpha value of 0 (100% transparent).

Your main video footage sits on this middle track. Because the top purple track is pure transparent, your video footage shows through completely with zero black box!

Bottom Track (Audio): Background Music / Sound Effects
